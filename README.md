# Karl Jason Ochava — Portfolio

A one-page portfolio built as a "Player's Handbook": an open book on a desk whose pages turn in 3D. On screens narrower than 900px the pages stack and scroll instead.

Built with React and Vite. There is no backend: contact is by email link.

## Run

```bash
npm run install:all
npm run dev      # http://localhost:5173
npm run build    # outputs client/dist
```

## Edit content

- `client/src/data/projects.json`: RobMon and claude-tools
- `client/src/data/experience.json`: the quest log
- `client/src/data/skills.json`: the character sheet
- `client/src/components/Pages/Pages.jsx`: page text and layout
- `client/public/img/`: photo and screenshots
- `client/public/Karl_Jason_Ochava_Resume.pdf`: the file the resume button downloads
